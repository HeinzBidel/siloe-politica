# Siloé — Política de Privacidade

A política de privacidade pública do aplicativo **Siloé — Bíblia Ilustrada**,
em português e inglês, servida pelo GitHub Pages:

<https://heinzbidel.github.io/siloe-politica/>

A Google Play exige uma URL pública e estável para a política de privacidade e
não aceita anexo. Este repositório existe só para isso: uma página, sem código
do aplicativo.

## A fonte é outra, e as duas têm de concordar

O texto vem de `loja/POLITICA-DE-PRIVACIDADE.md`, no repositório privado do
aplicativo. Quem mudar um muda o outro.

Em 08/09/2026 os dois discordavam: esta página dizia que o aplicativo **não**
declarava `android.permission.INTERNET`, o que deixou de ser verdade em 04/09,
quando as pranchas passaram a descer pelo Play Asset Delivery. A permissão
aparece na ficha da Play Store para qualquer pessoa — a página se contradizia
sozinha, num documento em que isso é grave. Está corrigido.
